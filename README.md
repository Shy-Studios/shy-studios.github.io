# Shy Studios website

Live at **https://shy-studios.github.io** (GitHub Pages).

- `index.html` – home page
- `app-ads.txt` – AdMob authorised sellers file (one line covers every Shy Studios app)
- `ghar-diary/privacy.html` – Ghar Diary privacy policy (the app links here)

To edit without any tools: open a file on github.com → pencil ✏️ → change the text → **Commit changes**.
The site updates by itself in about a minute.
